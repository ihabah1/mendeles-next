## 3. בדיקות אוטומטיות

מריצים מתוך `frontend/`:

```bash
npm run build
npm run start          # טרמינל נפרד
npm run test:a11y      # axe + Playwright
npm run audit:lighthouse
```

| Lighthouse — `/accessibility` | 100 | ≥ 90 |
